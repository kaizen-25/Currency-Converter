💱 Currency Converter

A simple and responsive real-time currency converter built using JavaScript and external APIs. This project allows users to convert between different currencies with up-to-date exchange rates.

🚀 Features
🌍 Convert between multiple currencies
⚡ Real-time exchange rates using API
🔄 Dynamic data fetching (no page reload)
📱 Responsive and user-friendly UI
💡 Fast and lightweight
🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
API: Frankfurter API

⚙️ How It Works
User selects base currency and target currency
Enters the amount
App fetches real-time exchange rates via API
Displays converted value instantly

🧠 What I Learned
Working with REST APIs
Handling asynchronous JavaScript (fetch/async-await)
Building interactive UI with dynamic updates
Managing real-time data in frontend applications

📦 Installation & Setup
Clone the repository
git clone https://github.com/kaizen-25/Currency-Converter.git
Navigate to the project folder
cd Currency-Converter
Open index.html in your browser
